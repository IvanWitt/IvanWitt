# IvanWitt - Fork from PipePipe

## About This Fork

IvanWitt is an independent fork of **PipePipe** (https://github.com/InfinityLoop1308/PipePipe), which itself is a fork of **NewPipe** (https://github.com/TeamNewPipe/NewPipe).

## IvanWitt Submodules

IvanWitt uses its own submodules:

### IvanWittClient
Custom client implementation for IvanWitt
- Repository: https://github.com/IvanWitt/IvanWittClient.git
- Purpose: Network communication

### IvanWittExtractor
Video extraction for multiple platforms
- Repository: https://github.com/IvanWitt/IvanWittExtractor.git
- Supports: YouTube, BiliBili, NicoNico, etc.
