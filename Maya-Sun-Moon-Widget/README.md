# Maya Sun/Moon Widget

Android-виджет по эскизам Ивана Витта: полукруг Солнца/Луны, текущее положение на дуге, центральное число майянской точечно-линейной записью и календарные даты майя.

## Логика виджета

- **Солнце имеет приоритет.** Пока Солнце над горизонтом, показывается солнечная дуга.
- После захода Солнца автоматически показывается лунная дуга.
- Если ночью Луна находится ниже горизонта, лунная схема остаётся на экране, но **жирный активный луч не рисуется**.
- На солнечной схеме риски направлены наружу, на лунной — внутрь.
- Жирный луч показывает **положение между текущим восходом и последующим заходом**, нормированное на полукруг:
  - 0° = восход;
  - 90° = середина интервала;
  - 180° = заход.
- Реальные высота и азимут Солнца/Луны также рассчитываются внутри приложения через Astronomy Engine; это позволяет в дальнейшем легко добавить отдельный режим истинной высоты/азимута.

## Центральное число

В настройках можно выбрать один из трёх режимов:

1. **Градус положения на дуге** — 0…180.
2. **Целые часы видимости** — длительность интервала `восход → заход` для **15-го числа текущего месяца**. Это сохраняет помесячную идею исходной таблицы.
3. **Современный час 1–12** — текущий локальный час в 12-часовом формате.

Число рисуется майянскими точками и чертами. Для значений больше 19 используется позиционная двадцатеричная запись с отчётливо разделёнными вертикальными разрядами, поэтому, например, 6 и 25 не выглядят одинаково.

## Календарь майя

Под полукругом отображаются:

- Длинный счёт;
- Цолькин;
- Хааб.

Корреляция задаётся пользователем. По умолчанию используется **GMT 584283**.

Для расчёта принята стандартная опорная пара `0.0.0.0.0 = 4 Ajaw 8 Kumk'u`.

## Геолокация и автономная работа

Приложение **не запрашивает разрешение INTERNET**.

При нажатии на виджет открывается экран настроек. Кнопка **«Обновить местоположение»** получает одну актуальную геопозицию через Android `LocationManager` и сохраняет координаты локально.

После этого:

- восход/заход Солнца;
- восход/заход Луны;
- текущее положение;
- помесячная длительность видимости

вычисляются **полностью офлайн**.

Астрономические расчёты выполняет [Astronomy Engine](https://github.com/cosinekitty/astronomy) (`io.github.cosinekitty:astronomy:2.1.19`, MIT).

## Обновление виджета

Android сам ограничивает стандартный `updatePeriodMillis` частотой не чаще примерно 30 минут. Дополнительно приложение ставит лёгкое одноразовое системное обновление примерно через 15 минут; Android вправе немного задержать его ради экономии батареи.

При открытии настроек, смене параметров или обновлении координат виджет перерисовывается сразу.
