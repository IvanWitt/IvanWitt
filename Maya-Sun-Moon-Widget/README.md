# Maya Sun/Moon Widget

Android-виджет по эскизам Ивана Витта: полукруг Солнца/Луны, положение на дуге, центральное число майянской точечно-линейной записью и календарные даты майя.

## Версия 0.2

- **Солнце имеет приоритет.** Пока Солнце над горизонтом, показывается солнечная дуга. Сразу после захода виджет переключается на Луну, даже если Луна ещё не взошла.
- На солнечной схеме риски направлены наружу, на лунной — внутрь.
- Жирный луч показывает текущее положение тела между восходом и заходом: `0° = восход`, `90° = середина интервала`, `180° = заход`.
- На самой дуге добавлена крупная точка положения. Она присутствует постоянно, пока в кеше есть данные восхода/захода. После захода остаётся у правого горизонта до следующего восхода.
- Старый маленький круг внутри полукруга удалён: он визуально смешивался с майянским числом.

## Центральное число

В настройках доступны три режима:

1. **Градус положения на дуге** — 0…180.
2. **Часов нахождения в видимости** — округлённая длительность фактического интервала `восход → заход` для отображаемого Солнца или Луны.
3. **Современный час 1–12** — текущий локальный час в 12-часовом формате.

Число рисуется майянскими точками и чертами. Значения больше 19 используют позиционную двадцатеричную запись с визуально разделёнными разрядами.

## Календарь майя

Под полукругом отображаются:

- Длинный счёт;
- Цолькин;
- Хааб.

Корреляция задаётся пользователем. По умолчанию — **GMT 584283**. Опорная пара: `0.0.0.0.0 = 4 Ajaw 8 Kumk'u`.

## Источник восходов и заходов

Основной источник — официальный **U.S. Naval Observatory Astronomical Applications API**, сервис `Complete Sun and Moon Data for One Day`:

`https://aa.usno.navy.mil/api/rstt/oneday`

API не требует ключа. Клиент передаёт необязательный идентификатор `ID=IvanWitt`.

При синхронизации приложение получает данные для вчерашнего дня, текущего дня и **четырёх следующих календарных дат**. Вчерашняя дата нужна, чтобы корректно восстановить лунный интервал, начавшийся до полуночи; дополнительный день вперёд гарантирует наличие следующего захода Луны вплоть до конца полного **72-часового автономного периода**.

Кеш содержит:

- восход и заход Солнца;
- восход и заход Луны;
- координаты;
- часовой пояс;
- время загрузки и срок актуальности.

После загрузки текущая точка на дуге и часы видимости рассчитываются на устройстве по системным часам без сетевых запросов.

## Автообновление через 72 часа

Когда кеш отсутствует, не соответствует координатам/часовому поясу или старше 72 часов, приложение ставит системное задание `JobScheduler` с требованием наличия сети.

- если интернет есть — USNO-данные обновляются;
- если интернет выключен — Android ждёт подключения;
- при появлении сети задание выполняется без постоянно работающего фонового процесса;
- после успешной синхронизации начинается новый 72-часовой период автономной работы.

Astronomy Engine (`io.github.cosinekitty:astronomy:2.1.19`, MIT) оставлен только как локальный резерв до первой успешной загрузки USNO или при отсутствии пригодного сетевого кеша.

## Геолокация

Кнопка **«Обновить местоположение и данные»**:

1. получает актуальные GPS/сетевые координаты;
2. очищает кеш предыдущей точки;
3. ставит загрузку USNO-данных в очередь;
4. пытается определить название города и страны через Android `Geocoder` с `Locale.ENGLISH`;
5. сохраняет всё локально.

В настройках можно включить **«Отображать текущий город и страну (English)»**. При наличии имени на виджете выводится строка вида `Moscow, Russia`.

## Обновление изображения виджета

Виджет локально перерисовывается примерно каждые 15 минут и сразу после изменения настроек, координат или успешной синхронизации. Android может немного задерживать фоновые события ради экономии батареи.
