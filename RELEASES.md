## How to Report Issues

If you find a bug:
1. Check existing issues first
2. Create new issue with:
   - Clear title
   - Device and Android version
   - Steps to reproduce
   - Expected vs actual behavior
   - Logs if available

## Update Instructions

### Automatic Updates
Some distributions (F-Droid, IzzyOnDroid) will notify you of updates.

### Manual Updates
1. Download latest APK from releases
2. Install APK (may need to enable unknown sources)
3. Your data will be preserved

See QUICKSTART.md for build instructions.
