## How to Contribute to Roadmap

1. **Suggest Features** - Open a discussion
2. **Report Issues** - Create an issue with details
3. **Submit Code** - Fork and create pull request
4. **Help Testing** - Test beta versions

## Release Schedule

Releases are made when:
- Significant bugs are fixed
- Important features are added
- Security updates needed
- Approximately every 1-2 months (no guaranteed schedule)

## Version Numbering

Format: `MAJOR.MINOR.PATCH`
- **MAJOR:** Major rewrite or complete feature overhaul
- **MINOR:** New features added
- **PATCH:** Bug fixes and minor improvements

Current: **5.2.4** (inherited from PipePipe)

## Getting Involved

### Report Bugs
- Check existing issues first
- Include device info and reproduction steps
- Provide logs if available

### Request Features
- Start a discussion
- Explain use case
- Don't request new platforms

### Contribute Code
- See [CONTRIBUTING.md](CONTRIBUTING.md)
- Follow code style
- Include tests

### Improve Documentation
- Fix typos
- Clarify instructions
- Add examples
